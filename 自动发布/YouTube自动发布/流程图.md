# YouTube 自动发布流程图

```mermaid
flowchart TD
  A["素材发现 / 上传"] --> B["下载源视频"]
  B --> C["生产成片"]
  C --> D["生成 ready_for_review 包"]
  D --> E["人工审核"]
  E -->|通过| F["候选状态 APPROVED"]
  E -->|返工| G["REVISION_REQUIRED"]
  F --> H["收集分类标签 / 关键词 / 源标题 / 源文案"]
  H --> I["源数据写入不可执行 JSON"]
  I --> J["Doubao 生成 pt-BR 标题 / 文案 / 5 标签"]
  J --> K["追加 YouTube 说明固定相关标签"]
  K --> L["自动匹配 YouTube 账号"]
  L --> M{"来源平台允许发布?"}
  M -->|否| N["记录 PUBLISH_BLOCKED_* 事件"]
  M -->|是| O["选择通用版成片"]
  O --> P["计算发布时间和每日上限"]
  P --> Q["写入 publications:SCHEDULED"]
  Q --> R["publish-worker 扫描到期任务"]
  R --> S["刷新 OAuth access token"]
  S --> T["YouTube resumable upload"]
  T --> U{"上传成功?"}
  U -->|否| V["publications:FAILED + error_json"]
  U -->|是| W["publications:PUBLISHED"]
  W --> X["写入 youtube_video_id / youtube_url"]
  X --> Y["candidates.published_flag=1"]
  Y --> Z["仪表盘状态列显示发布账号"]
```

## 状态机

```mermaid
stateDiagram-v2
  [*] --> READY_FOR_REVIEW
  READY_FOR_REVIEW --> APPROVED: reviewer approves
  READY_FOR_REVIEW --> REVISION_REQUIRED: reviewer requests changes
  APPROVED --> SCHEDULED: generate copy and enqueue publication
  SCHEDULED --> PUBLISHING: worker starts upload
  PUBLISHING --> PUBLISHED: YouTube returns video id
  PUBLISHING --> FAILED: upload or validation error
  FAILED --> SCHEDULED: manual retry
  PUBLISHED --> [*]
```
