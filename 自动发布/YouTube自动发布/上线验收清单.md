# YouTube 自动发布上线验收清单

## 部署前

- [ ] `config/pipeline.yaml` 中 `publishing.enabled` 为 `true`。
- [ ] 每个 YouTube 账号配置了 `label`、`channel_id`、`daily_limit`、`schedule_times`。
- [ ] `youtube_category_accounts` 已覆盖需要自动发布的内容分类。
- [ ] `blocked_source_platforms` 包含 `youtube`。
- [ ] 服务器环境变量已配置：
  - [ ] `JAGUARTV_GOOGLE_CLIENT_ID`
  - [ ] `JAGUARTV_GOOGLE_CLIENT_SECRET`
  - [ ] `JAGUARTV_GOOGLE_REDIRECT_URI`
  - [ ] `JAGUARTV_OAUTH_TOKEN_KEY`
  - [ ] `JAGUARTV_OAUTH_STATE_SECRET`
- [ ] Google OAuth 回调 URL 与服务器实际 URL 一致。
- [ ] 授权链接从接收回调的同一台线上服务生成，避免 `invalid OAuth state signature`。
- [ ] 如需 Doubao 自动文案，服务器已配置：
  - [ ] `JAGUARTV_DOUBAO_API_KEY`
  - [ ] `JAGUARTV_DOUBAO_ENDPOINT`
  - [ ] `JAGUARTV_DOUBAO_MODEL`
- [ ] `ffmpeg` 和 `ffprobe` 可用。
- [ ] `openssl` 可用。
- [ ] 仓库未提交任何真实密钥、token、Cookie、私钥。

## 授权验收

- [ ] 通过仪表盘完成 YouTube OAuth。
- [ ] `youtube_channel_auths.account` 与 `publishing.accounts` 的 key 一致。
- [ ] `youtube_channel_auths.channel_id` 与目标频道一致。
- [ ] refresh token 已加密保存。

## 队列验收

- [ ] 准备一个非 YouTube 来源候选，例如 Bilibili、TikTok、Douyin 或 Facebook。
- [ ] 候选已生成 `通用版` 成片。
- [ ] 审核通过后生成 `publications` 记录。
- [ ] 标题钩子不超过 70 个字符。
- [ ] 标签正好 5 个，其中 1 个固定为 `Jaguar TV`。
- [ ] YouTube 说明包含固定 `tags relacionadas` 标签段。
- [ ] 源标题和源文案只作为 JSON 不可执行素材进入模型 prompt。
- [ ] `account_label` 显示目标账号名称。
- [ ] `scheduled_at` 落在配置的发布时间段内。
- [ ] 超过 `daily_limit` 时会顺延到下一可用日期。

## 发布验收

- [ ] `publish-worker --once --dry-run` 能列出到期任务。
- [ ] `publish-worker --once` 能上传测试视频。
- [ ] 成功后 `publications.status=PUBLISHED`。
- [ ] 成功后写入 `youtube_video_id` 和 `youtube_url`。
- [ ] 成功后 `candidates.published_flag=1`。
- [ ] `events` 中存在 `PUBLICATION_PUBLISHED`。

## 仪表盘验收

- [ ] 内容库存状态列显示“审核通过”。
- [ ] 状态列下一行显示“已发布至 YouTube 账号：账号名”。
- [ ] YouTube 链接可点击并打开公开视频页。
- [ ] 发布队列页显示最新发布状态。

## 回滚方案

- [ ] 将 `publishing.enabled` 改为 `false` 可停止自动入队。
- [ ] 停止 systemd worker 可停止实际上传：

```bash
sudo systemctl stop jaguartv-youtube-publish-worker.service
```

- [ ] 已排队但未发布任务可手动改为 `FAILED` 或删除，操作前先备份数据库。
