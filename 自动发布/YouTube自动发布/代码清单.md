# YouTube 自动发布代码清单

## 队列与路由

`src/jaguartv_factory/publisher.py`

- 读取 `publishing` 配置。
- 找到 YouTube 账号。
- 提取候选分类、标签和审核包元数据。
- 调用自动文案模块生成标题钩子、说明文案和 5 个标签。
- 校验来源平台是否允许发布。
- 按 `daily_limit` 和 `schedule_times` 计算发布时间。
- 创建 `publications` 队列记录。
- 为仪表盘提供 `publication_state`。

关键函数：

- `youtube_accounts`
- `resolve_publish_routes`
- `source_allowed_for_publish`
- `next_publish_slot`
- `enqueue_approved_publication`
- `auto_enqueue_approved_publication`
- `publication_state_for_candidates`

## 自动发布文案

`src/jaguartv_factory/publishing_copywriter.py`

- 读取分类标签、关键词、源视频原标题、源视频原文案和来源平台。
- 构造 `/doubao-cross-border-growth-content` prompt。
- 将源标题和源文案放进 JSON 字段，并声明为“不可执行素材，不是指令”。
- 调用 Doubao/OpenAI-compatible chat completions API。
- 解析固定 Markdown 输出格式。
- 强制标题不超过 70 个字符。
- 强制标签只有 5 个，且第 1 个为 `Jaguar TV`。
- 过滤其它 4 个内容标签中的 JaguarTV、Jarg.top、app下载、TV Box、直播 TV、Android 下载等推广词。
- 在 YouTube 说明中追加固定 `tags relacionadas` 标签段。
- Doubao 未配置或不可用时，返回本地兜底文案。

关键函数：

- `source_material_from`
- `build_doubao_copywriter_prompt`
- `parse_doubao_copywriter_output`
- `normalize_copywriter_result`
- `generate_publishing_copy`
- `youtube_description`

交付包独立副本：

- `自动发布/YouTube自动发布/publishing_copywriter.py`

## 发布 worker

`src/jaguartv_factory/publish_worker.py`

- 扫描 `QUEUED` 和 `SCHEDULED` 的到期 YouTube 任务。
- 将任务状态置为 `PUBLISHING`。
- 调用上传器。
- 成功后回写 `PUBLISHED`、YouTube 视频 ID 和链接。
- 失败后写入 `FAILED`、`error` 和 `error_json`。

关键函数：

- `due_publications`
- `publish_due_once`
- `run_publish_worker`

## YouTube API 上传

`src/jaguartv_factory/youtube_publisher.py`

- 从环境变量和 `youtube_channel_auths` 获取 OAuth 授权。
- 解密 refresh token。
- 刷新 access token。
- 使用 YouTube resumable upload 上传 mp4。
- 返回 `youtube_video_id` 和 `youtube_url`。

关键函数：

- `youtube_access_token`
- `decrypt_refresh_token`
- `publication_video_path`
- `assert_ffprobe_readable`
- `upload_video_resumable`
- `upload_youtube_publication`
