QUESTIONS

Built for careful speed.

Does it publish automatically?

No. Phase 1 keeps automatic publishing out of the loop. Operators review outputs, claim downloads, and publish deliberately.

Can multiple agents work together?

Yes. Agents share the same factory database and avoid processing the same candidate concurrently.

What makes this different from a generic scheduler?

The workflow understands discovery, media files, render outputs, review decisions, rights status, and growth attribution as one record.
