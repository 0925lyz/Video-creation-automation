# JaguarTV YouTube 自动发布执行说明书

## 1. 功能边界

YouTube 自动发布由四个环节组成：

1. 人工审核：视频进入 `READY_FOR_REVIEW` 后，操作员在仪表盘点击通过。
2. 自动排队：候选状态变为 `APPROVED` 后，系统根据发布配置创建 `publications` 记录。
3. 定时发布：`publish-worker` 扫描到期任务，使用 YouTube Data API 上传成片。
4. 状态回写：成功后写入 YouTube 视频 ID、链接、发布时间，并在仪表盘展示发布账号。

不做的事情：

- 不绕过人工审核直接发布。
- 不把 YouTube 来源视频自动发布回受限 YouTube 消费账号。
- 不把 OAuth 密钥、refresh token 或服务器密钥写入仓库。

## 2. 关键数据表

`candidates`

- `status`：候选状态，只有 `APPROVED` 可进入发布队列。
- `published_flag`：发布成功后置为 `1`。

`publications`

- `candidate_id`：对应候选。
- `platform`：当前自动发布只处理 `youtube`。
- `account`：内部账号 key，例如 `jaguartv_vivo`。
- `account_label`：展示名称，例如 `jaguartv vivo`。
- `channel_id`：YouTube Channel ID。
- `scheduled_at`：计划发布时间，带时区。
- `status`：`QUEUED`、`SCHEDULED`、`PUBLISHING`、`PUBLISHED`、`FAILED`。
- `youtube_video_id`、`youtube_url`、`post_url`：发布成功后写入。
- `error`、`error_json`：失败原因。

`youtube_channel_auths`

- 保存每个 YouTube 账号的授权记录。
- refresh token 需要加密保存。
- 解密密钥来自环境变量 `JAGUARTV_OAUTH_TOKEN_KEY`。

`events`

- 记录 `PUBLICATION_QUEUED`、`PUBLICATION_STARTED`、`PUBLICATION_PUBLISHED`、`PUBLICATION_FAILED` 等流水。

## 3. 配置发布账号

在 `config/pipeline.yaml` 中启用 `publishing`：

```yaml
publishing:
  enabled: true
  timezone: America/Sao_Paulo
  youtube_category_accounts:
    足球类: jaguartv_vivo
  accounts:
    jaguartv_vivo:
      platform: youtube
      label: jaguartv vivo
      channel_id: UCxxxxxxxxxxxxxxxxxxxxxx
      daily_limit: 3
      schedule_times:
        - "11:00"
        - "15:30"
        - "19:00"
      allowed_source_platforms:
        - tiktok
        - douyin
        - facebook
        - bilibili
      blocked_source_platforms:
        - youtube
      content_tags:
        - 足球类
      default_privacy_status: public
      enabled: true
```

说明：

- `youtube_category_accounts` 控制分类到账号的路由。
- `daily_limit` 控制单账号每日发布上限。
- `schedule_times` 控制每天的可发布时段。
- `allowed_source_platforms` 和 `blocked_source_platforms` 是来源门禁。
- `default_privacy_status` 可设为 `public`、`unlisted` 或 `private`。

## 4. 配置 OAuth 环境变量

服务器 `.env` 或 systemd 环境中必须包含：

```bash
JAGUARTV_GOOGLE_CLIENT_ID=your-google-oauth-client-id
JAGUARTV_GOOGLE_CLIENT_SECRET=your-google-oauth-client-secret
JAGUARTV_GOOGLE_REDIRECT_URI=https://factory.jarg.top/oauth/youtube/callback
JAGUARTV_OAUTH_TOKEN_KEY=long-random-local-encryption-key
JAGUARTV_OAUTH_STATE_SECRET=long-random-state-secret
```

不要提交 `.env`。

Google OAuth Client 需要允许以下 scope：

- `https://www.googleapis.com/auth/youtube.upload`
- `https://www.googleapis.com/auth/youtube.readonly`

## 5. 授权 YouTube 账号

1. 启动仪表盘：

```bash
./.agents/skills/jaguartv-content-factory/scripts/factory.sh ui --host 127.0.0.1 --port 8787
```

或直接：

```bash
.venv/bin/jaguartv --config config/pipeline.yaml ui --host 127.0.0.1 --port 8787
```

2. 打开系统管理里的 YouTube 授权入口。
3. 选择账号 key，例如 `jaguartv_vivo`。
4. 跳转 Google 授权，选择对应 YouTube 频道账号。
5. 回调成功后检查数据库：

```bash
.venv/bin/python - <<'PY'
from jaguartv_factory.core import connect_db, load_config
config = load_config("config/pipeline.yaml")
con = connect_db(config)
for row in con.execute("SELECT account,channel_id,channel_title,updated_at FROM youtube_channel_auths"):
    print(dict(row))
PY
```

确认 `channel_title` 是目标频道，例如 `jaguartv vivo`。

## 6. 审核通过并自动入队

视频生产完成后会出现在 `workspace/ready_for_review/<candidate_id>/`。

审核通过方式：

```bash
.venv/bin/python - <<'PY'
from jaguartv_factory.core import load_config
from jaguartv_factory.dashboard import save_review

config = load_config("config/pipeline.yaml")
print(save_review(config, {
    "candidate_id": "替换为候选ID",
    "decision": "APPROVED",
    "reviewer": "operator",
}))
PY
```

或在仪表盘点击“通过”。

系统会自动调用发布排队逻辑：

- 校验候选是否为 `APPROVED`。
- 找到可发布的 `通用版` 成片。
- 根据内容标签匹配账号。
- 校验来源平台是否允许。
- 计算下一个发布时间。
- 写入 `publications`。

检查队列：

```bash
.venv/bin/jaguartv --config config/pipeline.yaml publish-status
```

模拟入队：

```bash
.venv/bin/jaguartv --config config/pipeline.yaml publish-queue --candidate 候选ID --dry-run
```

实际入队：

```bash
.venv/bin/jaguartv --config config/pipeline.yaml publish-queue --candidate 候选ID
```

## 7. 发布 worker

单次 dry run：

```bash
.venv/bin/jaguartv --config config/pipeline.yaml publish-worker --once --dry-run
```

单次真实发布到期任务：

```bash
.venv/bin/jaguartv --config config/pipeline.yaml publish-worker --once --limit 3
```

常驻运行：

```bash
.venv/bin/jaguartv --config config/pipeline.yaml publish-worker --sleep 60 --limit 3
```

生产环境建议使用 `systemd/jaguartv-youtube-publish-worker.service.example`。

## 8. 发布成功后的仪表盘显示

发布成功后状态列会显示：

```text
审核通过
已发布至 YouTube 账号：jaguartv vivo · YouTube 链接 · ovv30hJdww8
```

数据来自候选行的 `publication_state`：

- `account_label`
- `youtube_video_id`
- `youtube_url`
- `status=PUBLISHED`

如果显示仍是旧版页面，请刷新浏览器；本功能使用静态资源版本号避免旧 JS 缓存。

## 10. 常见故障

`YouTube account xxx is not authorized`

- 说明 `youtube_channel_auths` 没有对应账号授权。
- 重新走 YouTube OAuth 授权。

`missing Google OAuth client env vars`

- 服务器环境缺少 `JAGUARTV_GOOGLE_CLIENT_ID` 或 `JAGUARTV_GOOGLE_CLIENT_SECRET`。

`missing JAGUARTV_OAUTH_TOKEN_KEY`

- 服务器无法解密 refresh token。
- 配置 `JAGUARTV_OAUTH_TOKEN_KEY`，并确保与授权时使用的密钥一致。

`publication video file not found`

- 发布记录里的 `package_id` 或 `asset_id` 找不到对应成片。
- 检查 `workspace/ready_for_review/<candidate_id>/` 和服务器 `storage.root/review/<candidate_id>/`。

`YouTube upload failed`

- 查看 `publications.error` 和 `events.PUBLICATION_FAILED`。
- 常见原因是 OAuth 失效、视频文件损坏、YouTube API 配额不足或标题/描述不合规。

## 11. 安全注意事项

- 只发布人工审核通过的候选。
- 不提交 `.env`、OAuth token、Cookie、SSH key。
- 保持 YouTube 来源门禁开启。
- 每次改动发布逻辑后运行：

```bash
.venv/bin/pytest tests/test_publisher.py tests/test_dashboard.py -q
git diff --check
```
